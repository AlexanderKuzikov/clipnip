# DECISIONS — ClipNip

## 001: Пересоздание ReClip на Go + WebView (2026-08-04)

**Статус:** принято

**Контекст:** ReClip (Flask + yt-dlp, веб-UI на localhost) требует Python/venv; джобы в памяти теряются при рестарте; ffmpeg-путь захардкожен под одну машину; загрузка в браузер — через blob-скачивание.

**Решение:** новый проект ClipNip — desktop-приложение на Go: один exe (~8 MB), UI — системный WebView2 через loopback HTTP (`127.0.0.1:0`), движок скачивания — yt-dlp как subprocess, bootstrap yt-dlp/ffmpeg при первом запуске.

**Почему:**
- 1000+ сайтов поддерживает yt-dlp — его не переписываем, только оркеструем (exec + парсинг прогресса).
- WebView2 встроен в Windows 10/11 — раздувание Electron (380 MB в опыте пользователя) не нужно.
- Один exe без установщика; зависимости подтягиваются автоматически.
- Файлы сразу на диске — «Открыть папку» вместо диалога сохранения.

**Trade-offs:**
- Убийство процессов на Windows — только taskkill /T /F: exec.CommandContext на этой машине (Go 1.26) не убивает процессы вообще (проверено).
- Прогресс yt-dlp идёт в stdout в формате `--progress-template` — парсер завязан на формат строк (coupling к CLI).
- Джобы in-memory: состояние теряется при рестарте (осознанно, для личного инструмента достаточно).

**Атрибуция:** ReClip by averygan — MIT; copyright сохранён в LICENSE, указан в README.

## 002: Встроенные шрифты вместо Google Fonts (2026-08-04)

**Статус:** принято

**Контекст:** `<link>` на fonts.googleapis.com в head блокировал первый рендер — при недоступности CDN (РФ) окно висело тёмным.

**Решение:** шрифты PT Serif/PT Mono (woff2, кириллица) вшиты в embed (`web/fonts/`), отдаются с `/fonts/`, `font-display: swap`; фон документа задан инлайн (`html { background: #f4f1eb; }`).
